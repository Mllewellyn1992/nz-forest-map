# NZ forest map

Plantation and mānuka/kānuka forest blocks of 50 ha and up across New Zealand, with land titles, forestry rights,
Crown forest licences, forest managers (FSC register + firms' own lists) and Overseas Investment Office forestry buys.

Open `index.html` through the GitHub Pages link. Filters are kept in the address bar, so a copied link opens the same view.

Sources: Manaaki Whenua LCDB v6 (CC BY 4.0), LINZ parcels/titles/instruments (CC BY 4.0), search.fsc.org, LINZ OIO decisions,
firms' public summaries. Owner names are not included. Built by `ForestMap/code/build_map.py`.
